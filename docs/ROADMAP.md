# Roadmap

## Implemented

Household-scoped authenticated API, accounts, categories, transactions, transfers, generic assets, gold purchases and manual price, dashboard summaries, Persian mobile interface, Docker development setup.

## Next

Household invitation and membership management; edit/correction workflow for transactions; gold purchase as an explicit account-to-asset conversion; simple asset editing in the UI; backup/export of the SQLite database.

## Later

Property tracking, rental income, automatic gold pricing, monthly net-worth snapshots, budgets, analytics, CSV/Excel export, backups, shared family accounts, parent/admin mode, recurring transactions, notifications, and PWA installation.
